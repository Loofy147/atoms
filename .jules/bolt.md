## 2024-07-13 - [SQLite Connection Optimization in Idempotent Gateway]
**Learning:** SQLite's default mode uses synchronous=FULL and DELETE journaling, requiring multiple synchronous disk flushes per transaction. Furthermore, issuing schema-creation statements (`CREATE TABLE IF NOT EXISTS`) and committing on every connection incurs substantial, repetitive transactional overhead and locking. Enabling Write-Ahead Logging (WAL) and synchronous=NORMAL, combined with an initialization guard (`_initialized` flag) to bypass schema checks after the first load, speeds up SQLite connections and writes by over 25x.
**Action:** Always enable `PRAGMA journal_mode = WAL` and `PRAGMA synchronous = NORMAL` for SQLite-backed cache databases, and initialize schemas only once per process execution.
